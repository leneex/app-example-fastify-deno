# Fastify на Deno

Пример приложения [Fastify](https://fastify.dev/) на [Deno](https://deno.com/).

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Railpack |
| Путь до директории проекта | `/` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Команда запуска | `deno task start` |
| Порт приложения | `3000` |
| Путь проверки состояния | `/` |

Railpack видит `deno.json`: ставит зависимости и запускает задачу `start` — она даёт приложению
только нужные разрешения: сеть, переменные окружения, чтение файлов, имя хоста и список сетевых
интерфейсов (их читает Fastify при запуске). Приложение слушает порт из переменной окружения
`PORT` — её передаёт платформа, — а без неё `3000`.

## <a name="dev"></a>Локальный запуск проекта

```bash
# запуск приложения
deno task start
```
