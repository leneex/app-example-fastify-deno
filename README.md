# Fastify на Deno

Пример приложения [Fastify](https://fastify.dev/) на [Deno](https://deno.com/).

## Параметры деплоя

Выберите рантайм **Deno**, фреймворк **Fastify** и тип приложения **backend**. Приложение запускается как сервер.

| Параметр | Значение |
| --- | --- |
| Фреймворк | Fastify |
| Версия Deno | 2.7.14 |
| Тип приложения | `backend` |
| Команда запуска | `deno task start` |

## <a name="dev"></a>Локальный запуск проекта

```bash
# запуск приложения
deno task start
```
